# deepwell.games — full audit and upgrade report (Nov 2026)

Four games, four repositories, one hub. Every source file in each repo was read; bulk data was analysed with scripts.
Each section lists what was wrong, why it mattered, and what was changed.

---

## 1. APOGEE (repo `DeepWell`) — rare-answer trivia flight

Style kept: pixel-retro and minimal, as requested. The work went into questions, answers and matching.

### Drawbacks found

| # | Problem | Evidence | Fix |
|---|---|---|---|
| A1 | Questions were narrow, not broad. | 10,000 prompts, but **8,353 were "… starting with X"** variants and **8,591 were "from/in <country>"** ("Name an actor from Bhutan starting with K"). Only ~240 were broad. | Removed every letter and country variant. ~275 broad Wikidata prompts plus **~90 new hand-written everyday "survey" prompts** ("Name something people do at a party", "…in a kitchen", "a superpower you'd like", "a pizza topping", "a reason to throw a party"…). Flights alternate everyday and knowledge prompts. |
| A2 | Obvious answers were rejected. | "Name a mammal" rejected **cat, bear, whale, dolphin, horse, cow, monkey, zebra, fox, panda** (Wikidata species lists use scientific level names). "Name a fruit" rejected **pineapple, watermelon, cherry, kiwi, coconut, avocado**. | Common-name **overlays** for mammal, bird, fish, reptile, insect, fruit, vegetable, dessert, instrument, emotion, sport, superhero, board game, pasta, dance, martial art, soft drink, empire, dinosaur. All verified by tests. |
| A3 | Junk answers. | "Name a fruit" contained *Wikidata Sandbox* and *Apple of Discord*; "Name a dinosaur" offered birds (Swan, Thrush) as examples. | Blocklist applied at pack time; dinosaurs exclude birds (by id and name) and use `notParent: Aves` for future builds. |
| A4 | Partial names failed. | "winston" ≠ Winston Churchill, "petronas", "chrysler", "empire state", "denzel" all rejected. | New matcher: any distinctive word of a name finds the best-known answer ("winston" → Winston Churchill), plus plurals, missing spaces ("spiderman"), typos ("margret thatcher"), sound-alikes ("chaikovsky"), Roman numerals (John Paul I vs II). Generic words ("lake") never count alone; short look-alikes never drift ("pizza" ≠ Joe Pesci, "blue" ≠ glue). Confident matches count at once and say what they counted as. |
| A5 | Answers duplicated across questions. | v3 store only shared rows *inside* a country shard: 369,477 rows for 336,359 answers. | New **v4 store**: every answer written once for the whole game, each question is a small index into it. 203,824 answers, 13.2 MB raw / 5.0 MB gzipped (was 23.2 MB). |
| A6 | Pools capped small. | Most knowledge prompts stopped near 1,000 answers (actor: 952, with Donald Trump and Shakespeare at the top). | Targets raised to 3,000–6,000 per prompt with a lower popularity floor; local Wikidata expansion run (e.g. TV series 981 → 4,296) and the daily workflow keeps growing them. |
| A7 | Daily timer too short on phones. | 20 s to read and type. | 30 s per prompt. |
| A8 | Bugs. | Modules imported under two different URLs (`config.js` vs `config.js?v=…`), loading twice; `navigator.vibrate` errors before first tap; browser smoke test opened the hub instead of the game; `backfill-manifest` crashed without `data/packs`; 228 stale anchors for deleted prompts; two curated ids collided with Wikidata ids. | All fixed, plus a guard so curated ids can never shadow a Wikidata question. |

Checks: `node scripts/selftest.mjs` 1,394 passed / 0 failed; `node scripts/validate-data.mjs` passes (750 must-accept answers checked through the real matcher); every one of the 323 questions loads in the browser.

## 2. NEXUS RELAY — redesigned from scratch

### Why the old game was hard (root causes)

| # | Problem | Evidence |
|---|---|---|
| N1 | Free recall against a hidden list. | You had to type one of exactly 1,021 entities you could not browse; only 11% had aliases; search used the first 2 letters only, so "vienna" never found "Battle of Vienna". |
| N2 | Obscure, lopsided answers. | The "friendly" pool was mostly wars, battles and countries (128 wars/battles, 118 countries/cities); only 12 people in the whole dataset. |
| N3 | Warmer/colder was noise. | Heat was the max of four scores: in a simulation of random guesses 62% scored "Hot start". 55% of graph edges were synthetic. |
| N4 | Clues either useless or giving the answer away. | Wikidata clues were templates ("Filed in the X registry"), while the always-visible TYPE banner was the Wikidata description ("1982 studio album by Michael Jackson"). |
| N5 | Wrong data. | 12% of entities had a fake year 0; Russo-Ukrainian war dated 2100, gold −6000. |
| N6 | Bugs. | Lost rounds still scored and ranked; hardcore + tutorial soft-lock; missing `telemetry.bin` (404 on every load, validator crashed); Enter resubmitting the previous guess; autocomplete race; daily replayable without limit; settings not saved; the game screen pushed ~600 px below decorative panels on phones; render loop running on every screen. |

### New design: "Mystery Transmission"
- A famous mystery subject; **5 clues from vague to obvious**, **4 answer cards visible from the first clue** (tap, or keys 1–4). 500 → 100 points by clue.
- A wrong pick only greys that card and reveals the next clue — a round is lost only by a wrong pick on the last clue. Streak multiplier (×1.5 / ×2 / ×3), one 50/50 "Jammer" per run, optional Turbo timer (off by default).
- Bonus after every correct answer: "Which of these is connected to X?" (+100, never a penalty).
- Modes: Daily Broadcast (same 10 for everyone, one scored try, emoji share card), Quick Play, Channels (pick a category), Endless (3 lives). Skippable 30-second tutorial, Signal Archive collection, settings saved, music off by default.
- **Dataset rewritten**: 682 hand-written well-known subjects in 13 categories (≈300 people), each with aliases, era, region and 5 ordered clues; a validator rejects any clue that leaks the answer. Loaded per category (first load ≈73 KB).
- **Graphics**: full-screen WebGL2 "signal space" (nebula, radar, particle network, pulse on each clue) with Canvas2D fallback, glass cards, spring animations, confetti, an animated VEX-09 robot host. Phone: clue + 4 cards fit one screen; desktop: two columns. DPR ≤ 2, pauses when hidden, adapts quality, honours reduced motion; keyboard play and `aria-live` clues.
- Old code kept under `legacy/`, outside the build. Pages workflow now runs `npm ci`, typecheck, tests and build before deploying.

Checks: typecheck passes, 30/30 tests, build 62.7 KB JS (21.6 KB gzipped), played in the browser on phone and desktop with no console errors. Note: the 682 subjects' facts were written by AI and validated for structure and leakage, not independently fact-checked; a few numeric facts are worth a human spot-check.

## 3. HYPE RIOT — upgraded (pixel canvas replaced by a high-end arena)

### Drawbacks found
| # | Problem | Evidence |
|---|---|---|
| H1 | Exploitable rounds. | "Clash" cards: the bigger value was almost always side A, so "always pick A" won; "Which came FIRST?" was scored bigger-wins (Nintendo 1889 marked wrong) and labels showed the values; claims were 44 fact / 16 cap, so "always FACT" scored 73%. |
| H2 | Broken scoring. | Combo tags matched 100% or 1–3 answers; "Starts with T" never matched The Weeknd; pitch "verb" list was full of nouns (pizza, gorilla) and cut off at "k"; crowd variance identical for every pitch that day; padding with spaces dodged the length penalty; scores could go negative. |
| H3 | Economy farm. | Replaying Daily repaid coins, XP and the streak bonus every time. |
| H4 | Wrong or unsuitable content. | Prompts with answers that do not fit ("Dinosaurs" with Orca, "Breakfast" with French Fries, "Anime" with Frozen); false "facts" (dynamite contains peanuts); controversial creators in a teen game (Andrew Tate, Sneako, …). Only 30 prompts, so the Daily repeated every 30 days. |
| H5 | Bugs. | Switching tabs froze the timer (searchable answers); a pack with < 4 cards soft-locked; double-tap answered two cards; correct answer never shown on timeout; boot race (`pack_NaN`); a 404 for `entities.bin` on every load; data builds never redeployed the site; dither transition inverted; canvas squashed on phones. |

### What changed
- **Content (hand-written, reviewed):** 122 Top-5 prompts with 6,414 answers (30–60 each, with aliases), 260 Fact-or-Cap claims (130/130), 106 clashes ("more" and "earlier/less" types, random sides, no values on labels), 115 "zoom-in" emoji mysteries, 34 pitch templates, 330 wildcards, 1,192-word verb list. Daily cycles all 122 shows before repeating. Denied-people list enforced by tests.
- **Rules:** fair combos (20–40% of answers qualify), whole-word pitch scoring, one scored Daily per day (replays are practice), streak bonus once per day, wall-clock timers, input lock after each card, missed answers revealed at round end.
- **Matching:** plurals, apostrophes, spacing, surnames ("lebron" → LeBron James), typos only from 5 letters, no prefix guessing.
- **Graphics/UI:** full-screen hi-DPI arena — sweeping spotlights, LED jumbotron, perspective crowd with glowsticks reacting to a visible HYPE meter, confetti, round splashes, vector MC VOLT with 11 moods; glass HUD over the arena; fits one phone screen; DPR ≤ 2, auto quality, pauses when hidden, reduced motion; keyboard shortcuts; favicon and share tags.
- **Engineering:** dev server serves the data; Pages workflow rebuilds the dataset, typechecks, tests and builds before deploying; the data workflow now triggers a redeploy.

Checks: typecheck passes; tests engine 17/17, web 16/16, pipeline 11/11; build 89 KB JS (33 KB gzipped); played in the browser on desktop and phone, no console errors.
Open: old unused v1 files (`pipeline/corpus/entities_cat01–10.py`, `pipeline/wikidata_ingest.py`, `public/data/v1/entities.json`, `public/data/v1/trie_shards/`, `art-source/neon_32.gpl`) are still in the repo and still copied to the site — deleting them needs your OK. Synced Party Room matches are not built (button hidden).

## 4. LUMEN VAULT — upgraded

### Drawbacks found
| # | Problem | Evidence |
|---|---|---|
| L1 | Unsolvable puzzles. | Venn sockets held one tile, but two tiles shared a region in venn-01 and venn-05: solvable only by spending a hint. None of the verifiers checked socket capacity. |
| L2 | Unreachable content. | venn-01 and chrono-01 were in no wing, so 2 of 16 artifacts could never be collected. |
| L3 | Daily never changed. | `daily/latest.json` was fixed at 2026-11-26; the workflows the README mentioned did not exist. |
| L4 | Bad data. | 78 obscure Wikidata films with raw "Q123" titles, wrong regions, a fixed notability score — three were adult films. Wrong facts: Hubble/Voyager agency tags, the Gutenberg press in an "eastern" chain, a "creatures of the deep" forge with the axolotl, Sputnik tagged Europe. `npm run data` would wipe the shipped dataset. |
| L5 | Weak matching. | "Moby-Dick" rejected by the profanity filter; "Schindler's" broken by the apostrophe; no accent folding; "apollo 12" resolved to Apollo 13; "me" accepted as Mount Everest; unknown real answers counted as wrong. |
| L6 | No real deduction. | Turning on all four Astrolabe filters always left exactly the answer; Chrono clues alone did not fix the order. |
| L7 | Mobile / UX. | Snap animation jumped, tiles could not go back to the tray, no auto-scroll, astrolabe sectors overlapped on phones, map labels ~7 px, fonts never loaded, no keyboard support, back button left the app. |

### What changed
- **Content (hand-curated):** 766 entities across 14 domains, 64 chambers (16 Venn, 16 Chrono, 16 Forge, 16 Astrolabe) in 8 wings, 64 artifact cards with unique motifs and factual lore. Every chamber is machine-proved solvable and unique (TypeScript proofs + independent Python verifier, 64/64). Forge pools have 8–19 answers.
- **Puzzles:** multi-tile Venn rings; Chrono clues proved to give exactly one order; Astrolabe is real deduction (riddles, proved to leave one candidate with no single riddle enough); daily vault computed from the UTC date in the browser, new every day.
- **Matching:** accents, apostrophes, number words and Roman numerals, partial names ("night music" → Eine kleine Nachtmusik), same-title disambiguation by the chamber's rules; unknown names never cost anything.
- **Graphics/UI:** WebGL background of slow brass light and drifting dust over obsidian (DPR ≤ 2, paused when hidden, still frame with reduced motion); bundled Cinzel + Inter fonts; metallic SVG; vertical constellation map where gold pours to the next node; unseal sequence (glow, sparks, chime, count-up, card flip); holographic tilting artifact cards and a cabinet gallery. Drag with smooth snapping, tap-to-place, swapping, keyboard play, hash routing; no horizontal overflow at 360 px.
- **Engineering:** `npm run data` only reads seeds and refuses to write if any proof fails; Wikidata ingest fixed (sitelinks order, no bare-QID titles, adult genres excluded); UTF-8 everywhere; Pages workflow runs typecheck and all tests; data builds now redeploy; new pull-request CI.

Checks: typecheck passes; 24 engine + 6 app tests pass (11 Python tests pass where pytest is installed, CI installs it); build 90 KB JS (31 KB gzipped); played in the browser under the real `/Lumen-vault/` path. Note: old saves keep prisms, score and settings, but chamber progress starts fresh (chambers were rewritten). Facts were checked from knowledge, not web lookups.
